# Attribution

## Audio clips (`clips/`)

72 team-radio clips redistributed from the Hugging Face dataset
**[MikCil/f1-team-radio](https://huggingface.co/datasets/MikCil/f1-team-radio)**,
licensed **CC BY 4.0**. Clips have been converted and renamed; the original
dataset row id for every clip is recorded in `radio.csv` (`dataset_id`, `row`)
so each one can be traced back to its source record.

## Lap timing (`laps.csv`)

Lap times, compounds and positions for the 2019 Brazilian Grand Prix, retrieved
via **[FastF1](https://github.com/theOehrly/Fast-F1)**, which sources the
official F1 timing feed. Used here for non-commercial, educational purposes.
